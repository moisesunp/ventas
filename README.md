# Ventas

Proyecto académico de escritorio para estudiar la evolución de un sistema pequeño de ventas y usuarios mediante patrones de diseño.

## Tecnologías previstas

- Java 21
- Maven
- JavaFX
- SQLite

## Evolución didáctica

- v0.1: usuarios y productos
- v0.2: ventas y detalle de venta
- v0.3: crecimiento de condicionales
- v0.4: Strategy
- v0.5: Factory
- v0.7: Observer
- v0.9: State

El objetivo es observar primero el problema de diseño y luego introducir cada patrón como una refactorización justificada.
